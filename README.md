# MTU Attendance Portal — Native Google Android Project

This version packages the uploaded web app and adds native Android Google Sign-In using Credential Manager.

## Firebase
- Project: attendants-mtu
- Android package: com.mtu.attendance
- `app/google-services.json` is included.
- SHA-1 and SHA-256 were registered in Firebase.
- Google provider is enabled.

## Native login flow
Android Credential Manager obtains a Google ID token using the Web OAuth client ID generated by the Google Services plugin. The token is passed to the local WebView through a small JavaScript bridge. The existing Firebase Web SDK then calls `GoogleAuthProvider.credential(idToken)` and `signInWithCredential()`. This preserves the existing Firestore user/session logic.

## Build
Open the `MTUAttendance-NativeGoogle` folder in Android Studio or a cloud Android build service, sync Gradle, then build an APK.

Debug output:
`app/build/outputs/apk/debug/app-debug.apk`

## Release signing
The user's release keystore is intentionally NOT included. Keep it private and use the same keystore for every future release.

## Build without Android Studio — GitHub Actions

1. Create a private GitHub repository.
2. Upload the contents of this project to the repository (not the ZIP file itself).
3. Ensure `app/google-services.json` is present.
4. Open the repository's **Actions** tab.
5. Select **Build MTU Attendance APK** and run the workflow.
6. When it finishes, open the workflow run and download the artifact named `mtu-attendance-debug-apk`.
7. Extract the artifact and install `app-debug.apk` on your Android phone.

This workflow builds the debug APK in GitHub's cloud runner, so Android Studio is not required on your laptop.

For the production release APK, we will add the release keystore as encrypted GitHub Actions secrets. Do not upload your `.jks` file or keystore password to the repository.
